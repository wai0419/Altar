# Altar

> ✝️ 攻擊場上的怪物，將牠們扛回祭壇獻祭換取分數，看誰（或哪一隊）能在時限內獻祭最多！
> 一款以「攻擊 → 搬運 → 獻祭」為核心玩法的 2–4 人本機多人派對遊戲。

**製作團隊**：108 級畢業專題遊戲組（4 人團隊）
**製作期間**：2022 年，大三升大四畢業專題製作
**遊戲類型**：3D 本機多人派對動作遊戲（2–4 人同樂，支援手把加入）

---

## 專案簡介

《ALTAR》是我大學畢業專題與另外三位同學合作開發的多人派對遊戲。玩家們扮演可愛又帶點哥德暗黑風格的角色，在教堂、醫院、墓園等不同主題的場景中，合力或互相競爭攻擊四處出沒的怪物（殭屍、蝙蝠等），並將擊倒的怪物扛起、搬運回場地中央的祭壇獻祭，每成功獻祭一隻即可得分。遊戲以「心跳／心電圖」風格的倒數計時器營造緊張感，玩家需在時限內達成獻祭數量目標，過關後依表現獲得 1–3 星評價，並穿插角色間的對話劇情銜接各關卡，兼具動作玩法與輕鬆詼諧的敘事氛圍。

### 核心玩法迴圈
1. **尋找／攻擊怪物**：場景中會出現不同種類的怪物，玩家需接近並攻擊使其倒下
2. **搬運怪物**：擊倒後可將怪物扛起（角色頭上會頂著怪物移動）
3. **獻祭得分**：將怪物搬運至祭壇上放下，觸發獻祭效果並累計分數（畫面左上角以「目前分數／目標分數」呈現，例如 0/3）
4. **時限挑戰**：所有動作需在心電圖造型的倒數計時器歸零前完成，達成目標即可過關並依剩餘時間／表現獲得星級評價

### 支援機制
- **本機多人即時加入**：遊戲進行中可隨時按下手把或鍵盤按鍵加入戰局，最多支援 4 位玩家同時遊玩
- **多主題關卡**：教堂祭壇、詭異醫院、荒涼墓園等風格迥異的場景，每關搭配不同怪物與環境機關
- **角色互動劇情**：關卡之間穿插角色對話，補足故事背景並銜接關卡難度與主題轉換

## 我負責的部分

在這個四人團隊中，我主要負責 **程式設計互動機制** 與 **美術特效整合** 兩大部分：

### 🎮 互動機制程式設計
- **核心戰鬥循環程式設計**：玩家攻擊判定、怪物受擊倒下狀態、拾起／扛起怪物、搬運移動限制、於祭壇放下觸發獻祭與加分邏輯
- **本機多人加入系統**：實作「遊戲進行中隨時可按鍵加入」的動態多人系統，處理玩家角色動態生成、控制器（鍵盤／手把）綁定與 UI 提示（如畫面下方「Tap CTRL to join!」提示列）
- **關卡計分與計時系統**：心電圖式倒數計時器、目標分數（X/3）判斷、時間到或分數達標時觸發關卡結算（Level Complete）與星級評價邏輯
- **怪物基礎 AI 行為**：怪物的徘徊、追擊或反擊玩家等行為邏輯，依關卡主題調整怪物種類與行為參數
- **關卡流程與對話系統整合**：關卡間過場對話的觸發、按鍵繼續對話（按 R 繼續）等流程控制

### ✨ 美術特效整合
- **UI 特效整合**：心電圖動畫式倒數計時器、獻祭分數圖示、星級過關評價動畫等介面視覺效果的實作與細節調校
- **場景氛圍整合**：教堂的燭光、紅毯與十字架裝飾，墓園的蝙蝠飛舞、陰森樹枝剪影，醫院關卡的詭異手術器材佈置等，將美術資源整合進場景並調校燈光氛圍
- **角色與怪物動畫整合**：玩家攻擊、扛起怪物、行走等動作動畫，以及怪物受擊、倒下等反饋動畫的整合串接
- **粒子與環境動態效果**：如蝙蝠群飛、環境粒子飄散等動態細節，強化各主題關卡的沉浸感與生命力

## 技術亮點

- **動態加入的本機多人架構**：不同於一開始就固定人數的多人遊戲，本作支援遊戲進行中隨時加入，需妥善處理動態生成角色、輸入裝置綁定與 UI 同步更新
- **搬運型互動機制**：「攻擊 → 拾起 → 搬運 → 放置」的多階段互動設計，比單純的攻擊得分玩法更具策略性與趣味性（例如是否要冒險搬運怪物穿越危險區域）
- **多主題內容管線**：同一套核心玩法系統可套用於教堂、醫院、墓園等不同美術風格與怪物設定的關卡，展現系統設計的擴充彈性
- **輕度敘事包裝動作玩法**：以角色對話與關卡轉場故事，包裝原本單純的動作玩法，提升遊戲的完整度與可玩性
